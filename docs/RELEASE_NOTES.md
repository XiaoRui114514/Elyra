Elyra 0.2 development release

Adds typed plist editing and verified local backups, file/version tools, bounded ZIP/tendies inspection, Dynamic Island configuration inspection and activity appearance records. Includes responsive iPhone/iPad navigation and persistent English/Simplified Chinese language settings.

System configuration access and system Dynamic Island geometry changes are not implemented. The attached arm64 device IPA is unsigned and requires legitimate signing/provisioning. Physical installation and iOS/iPadOS 27 system behavior have not been tested. Source identity, checksums and test coverage are in TEST_REPORT.md.
